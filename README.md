# Janhavi Wararkar | Portfolio

**Live site:** https://janhaviwararkar.github.io

Personal portfolio of Janhavi Wararkar, Junior Embedded Engineer working on embedded software and firmware for electric vehicles.

## What's on the site

- **Experience** at DAO EVTech, from IoT Intern to Junior Embedded Engineer
- **Selected work**
  - Distance-to-Empty (DTE) algorithm, with an interactive model you can try
  - Hall sensor failure analysis inside a BLDC hub motor
  - RS-485 BMS monitoring tool, with a clickable frame decoder
  - CAN bus reverse engineering on a production electric scooter
- **Projects** from my undergrad: Smart Transportation Hub, LoRaWAN health monitoring and a voice-based notice board
- **Training, education, skills and certifications**

## Built with

A single `index.html` using plain HTML, CSS and JavaScript. It has no frameworks, no build step and no dependencies apart from Google Fonts.

- Hand-drawn inline SVG illustrations, animated with CSS keyframes and SVG animation
- Light and dark themes that follow your system setting
- Responsive layout for phones and desktops
- Respects `prefers-reduced-motion`

## Run locally

Open `index.html` in any browser. That's it.
